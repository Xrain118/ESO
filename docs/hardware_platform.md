## 3. 飞行器本体与倾转动力系统

### 3.1 构型

飞行器不是普通固定桨轴多旋翼，而是三组双轴倾转动力单元组成的六旋翼平台：

- 三个动力组在模型中的方位角分别为 0°、120°、240°。
- 每组包含两个旋翼，因此整机共有六个旋翼和六路动力输出。
- 每组包含内、外两个倾转角，对应两个倾转自由度；三组共六个倾转关节。
- 同组两个旋翼随动力组倾转，旋翼推力方向由所属动力组的倾转状态共同决定。
- 文档中的“六路独立推力”和“六 Motor＋六 Servo”描述当前适配接口能力，不足以证明实机六路动力及六路倾转执行器已全部完成独立响应测试。

### 3.2 与硬件几何相关的模型参数

以下数值来自当前仿真模型，仅用于描述模型中的机械布置，**不是实物测量结果**：

| 参数            | 模型数值                    | 含义                        |
| ---           | ---:                    | ---                       |
| 动力组分布半径 `ρu`  | `1.2 / √3 m`，约 0.6928 m | 三个动力组在机体平面内的模型分布半径        |
| 同组两旋翼间距 `d`   | 0.36 m                  | 同一动力组内两个旋翼的横向间距           |
| 动力单元基准高度 `hu` | 0.06 m                  | 动力组基准点相对机体参考点的模型高度        |
| 旋翼高度偏移 `hr`   | 0.038 m                 | 旋翼沿倾转局部轴系相对动力组基准点的偏移      |
| 机体位置参考点       | `uav_base_link` 原点      | 模型几何和安装位置的共同参考点，不默认等于整机质心 |

- 六个电调的型号、额定电流、供电制式及控制输入形式；

## 4. 双 RoArm-M3 机械臂

### 4.1 数量、预定布置与关节组成

平台计划配备左右两套 RoArm-M3。根据用户最新说明，机械臂**不再按机腹安装或机腹倒置安装描述**，当前预期布置在机腹与机头之间、类似人肩膀的机肩区域。这里的“机肩”只表示预定布置区域，不代表已经确定机械安装面、左右间距、前后位置或高度。

单臂从根部到末端依次为：

1. 底座转动关节；
2. 肩关节；
3. 肘关节；
4. 腕俯仰关节；
5. 末端滚转关节；
6. 独立夹爪。

每臂只有前五项构成五个运动关节。肩部由两个舵机共同驱动同一个机械自由度，因此“七个物理舵机”不等于“七个独立运动关节”。每臂七个舵机的 ID 范围为 11～17；现有文档涉及肩部双舵机的合成，但没有给出全部 ID 与关节的实物映射核验结果。

### 4.2 安装位置与姿态的当前状态

| 项目 | 当前结论 |
|---|---|
| 预定布置区域 | 机腹与机头之间，类似人肩膀的机肩位置 |
| 相对机体参考点的具体安装位置 | 未定 |
| 具体安装高度 | 未定 |
| 左右臂安装姿态 | 未定 |
| 是否倒置及倾转角度 | 未定，不再采用旧模型中的绕 X 轴翻转 180°作为当前方案 |
| 旧模型安装坐标 `(0, ±0.15, -0.05) m` | 仅是旧仿真模型数值，不代表当前预定方案，不能作为实机安装外参 |

后续只有在机械安装方案确定并完成实物测量后，才能填写左右臂相对机体参考点的平移、旋转及机械零位。

### 4.3 连杆几何的模型值与固件差异

下表为项目模型使用的局部几何向量，不是本次实物测量值：

| 几何项 | 当前项目模型值 | 说明 |
|---|---|---|
| `h` | 126.06 mm | 基座或立柱等效高度 |
| `a` | `(30.00, 0, 236.82) mm` | 第一段主要连杆等效向量 |
| `b` | `(0, 0, 144.49) mm` | 第二段主要连杆等效向量 |
| `c` | `(13.29, 0, 171.67) mm` | 末端段等效向量 |

已核查固件中的末端横向偏移为 13.69 mm，而项目模型使用 13.29 mm，二者相差 0.40 mm。该差异尚未通过实物测量判定哪一方更接近实际硬件，不能在硬件说明中静默统一。

### 4.4 舵机反馈与测量边界

每个 ESP32 对七个舵机逐项采集，资料列出的反馈量包括：

- 位置；
- 电流；
- 速度；
- 负载；
- 电压；
- 温度；
- 故障状态。

这些反馈存在以下硬件测量边界：

- 速度单位尚未核实，不能擅自换算成标准角速度；
- 电流通过厂家线性系数得到的力矩只是未标定粗估，不是独立扭矩传感器测量；
- 电流粗估受电流零偏、效率、摩擦、温度和测量口径影响；
- 肩部两个舵机不是同步 ADC 采样，未经时间对齐和方向核验不能直接当作可靠差值；
- 舵机反馈不能直接提供机械臂末端接触力、关节精确输出扭矩或机械臂底座的六维力与力矩。

## 5. 机载计算、飞控与通信硬件

### 5.1 机载上位机与 PX4 飞控

平台按“机载上位机＋PX4 飞控”分工配置：

- 机载上位机运行 ROS 2，并连接双臂 ESP32 和飞控；
- PX4 飞控自带 IMU，并连接飞行执行机构；
- 飞控与上位机之间采用 uXRCE-DDS 通信；
- 首选物理链路为有线串口或以太网；
- 热点用于地面监控，不作为首选机载主控制链路。

这里能确认的是计算与通信架构，不能据此补写上位机或飞控的具体产品型号。两者的硬件型号、可用物理接口、实际接线、供电和实机固件版本均留待用户后续提供机上硬件资料后补充。

### 5.2 双 ESP32 与有线串口

左右机械臂各使用一个 ESP32，优先通过有线串口分别连接机载上位机，形成两路独立硬件链路。

| 项目 | 当前设定 | 属性与限制 |
|---|---:|---|
| 上位机与单侧 ESP32 串口 | 921600 baud，8N1 | 设计决策，不是实测吞吐能力 |
| ESP32 与舵机总线 | 1 Mbps | 当前总线设定 |
| 主动遥测目标频率 | 50 Hz | 固件目标，可在 1～50 Hz 配置；实机持续频率待测 |
| 主机设备路径 | 使用 `/dev/serial/by-id/...` | 左右设备必须按实物 ID 明确配置，不自动猜测 |
| USB 转串口 | 文档提及其复位电路影响 | 转换器型号和实际复位表现未确认 |

两个 ESP32 的时钟不能视为互相同步，也不能直接与主机时钟相减获得真实硬件时延。文档要求保留采样和接收时刻，但当前资料没有给出硬件时间同步装置或实测同步精度。

实际设备需要烧录支持主动遥测流的固件；本次资料明确说明当时没有烧录，双臂实机固件版本和反馈能力仍须核实。

## 6. 导航与传感硬件

### 6.1 GNSS

**平台当前没有 GNSS 辅助导航硬件。**旧文档中“用户已确认存在 GNSS 等辅助导航”的表述已经被用户最新说明否定，不再作为当前平台配置。本文不列 GNSS 模块、天线、RTK 或差分定位配置，也不宣称平台具备基于 GNSS 的绝对定位或厘米级定位能力。

### 6.2 飞控自带 IMU

平台 IMU 为飞控硬件自带，不是当前另行确认的外置独立 IMU。飞控及内置 IMU 的具体型号、数量、安装方向、安装杆臂、量程和标定情况，待用户后续提供机上硬件资料后补充。

除飞控自带 IMU 和舵机反馈外，其他实机传感器尚未明确。尤其是：

- 未列出机械臂末端六维力传感器或机械臂底座六维力传感器；
- 未确认真实旋翼推力传感器；
- 分配输出或模型重建的推力不能当作实测推力；
- 没有电压、电流等实测数据时，不能把控制量代理指标称为整机实测能耗。
