# ESO 与外部仿真仓库边界

## 唯一代码源

- `/home/ubuntu/ESO`：机载电脑实际运行的 ROS 2 代码。PreGME 算法只能在此实现和修改。
- `/home/ubuntu/Dragonfly`：四旋翼数字样机、Gazebo、PX4 SITL、场景、故障注入和仿真验收；Dragonfly 仅是该外部仓库的既有名称。
- `/home/ubuntu/PX4-Autopilot`：应用版本化补丁后的外部编译树，不是项目源码或文档的唯一来源。

依赖方向只能是外部仿真仓库加载已安装的 ESO ROS 2 包。禁止 ESO 导入外部仿真仓库源码，禁止在外部仿真仓库中维护第二份 PreGME 数学实现，也禁止用符号链接绕过这一边界。

## 数据边界

ESO 正式输入来自 PX4 uXRCE-DDS：估计位置和速度、姿态、角速度、飞行状态及控制分配状态。Gazebo 真值只能由外部仿真仓库的评估节点读取，不得转发给 ESO 控制节点。既有 `/dragonfly/truth` 名称只保留为禁止进入控制链的主题字面量。

ESO 输出止于机体 Z 轴总推力、三轴力矩、控制模式和必要的 PX4 命令。四路电机指令属于 PX4 标准多旋翼控制分配器所有；ESO 不直接控制电机。

## 参数边界

- ESO 保存论文参数、实机标定值、数据有效期和安全阈值。
- 外部仿真仓库保存四旋翼仿真模型质量、惯量、Gazebo 执行器和仿真假设。
- 仿真需要实机控制参数时，通过安装后的 ESO 配置包读取；不得复制后独立修改。
- 四旋翼平台参数与论文标称参数分层保存。当前飞行平台质量为 1.7 kg（含电池和机载设备，不含双臂），双臂质量为 1.947 kg；连接件、最终质心和惯量仍需测量。
